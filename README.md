# YouTube Comments Sentiment Analysis

A Python project that collects YouTube comments using the YouTube Data API and analyzes audience sentiment and engagement.

## Features

- Fetch YouTube comments using YouTube Data API
- Sentiment analysis using NLTK VADER
- Classify comments as Positive, Negative, or Neutral
- Analyze likes and comment length
- Find frequently used words and mentions
- Store data in SQLite
- Generate visualizations using Matplotlib and Seaborn

## Tech Stack

- Python
- Pandas
- NLTK
- YouTube Data API
- SQLite
- Matplotlib
- Seaborn
- Google Colab

## Results

The project analyzed **89,989 comments** and identified overall audience sentiment, engagement patterns, and frequently discussed topics.

## How to Run

1. Open `comments_analysis.ipynb` in Google Colab.
2. Add your YouTube API key as `YOUTUBE_API_KEY`.
3. Set the required YouTube video ID.
4. Run all cells.
